# Code Of Conduct

RecallWeave contributors should keep collaboration practical, respectful, and
evidence-based.

## Standards

- Discuss code and behavior, not personal attacks.
- Protect user privacy. Do not pressure contributors to share raw memories,
  transcripts, credentials, or private diagnostics.
- Keep benchmark claims inside the evidence collected.
- Mark speculation as speculation.
- Prefer small, reviewable changes.

## Enforcement

Maintainers may edit, hide, or remove comments and contributions that expose
private data, include secrets, or make unsupported claims. Security and privacy
issues take priority over feature work.
