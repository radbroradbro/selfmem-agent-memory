# Changelog

## 0.1.0-alpha.0

- Renamed the public project to RecallWeave.
- Added Apache-2.0 licensing.
- Kept `selfmem_canary` as the compatibility runtime id for Hermes and OpenClaw.
- Documented local-first writes, hosted read-through, lifecycle events, and
  update flow.
- Added public security, compatibility, visual, and release-checklist docs.
- Preserved the rule that credentials, raw memories, private diagnostics, and
  personal container mappings never belong in the repository.
